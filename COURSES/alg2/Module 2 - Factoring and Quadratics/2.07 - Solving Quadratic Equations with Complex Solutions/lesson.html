2.07 – Solving Quadratic Equations with Complex Solutions

Una ecuación cuadrática puede tener soluciones reales o complejas. Las soluciones complejas aparecen cuando el discriminante es negativo.

Recordemos el discriminante:

D = b2 - 4ac
  • D > 0 → dos soluciones reales
  • D = 0 → una solución real doble
  • D < 0 → dos soluciones complejas

Cuando D es negativo, aparece un número imaginario porque debemos tomar la raíz de un número negativo.

Recordemos que:

-k = i k

Donde i es la unidad imaginaria:

i = -1

Ejemplo: Solución Compleja

Resolver: x2 + 4x + 13 = 0

  1. a = 1, b = 4, c = 13
  2. D = 4² - 4(1)(13) = 16 - 52 = -36
  3. Como D es negativo, habrá soluciones complejas.
  4. Aplicamos la fórmula cuadrática:
x = -4 ± -36 2(1)

Convertimos la raíz negativa:

-36 = 6i

Soluciones finales:

x = -42 ± 6i2

Es decir:

x = -2 + 3i y x = -2 - 3i
