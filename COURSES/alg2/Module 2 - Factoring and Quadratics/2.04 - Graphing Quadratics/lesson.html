2.04 – Graphing Quadratics

Una función cuadrática es una función cuyo término más alto es x². Su gráfica es una parábola, una curva en forma de U que puede abrir hacia arriba o hacia abajo.

Forma estándar:

y = ax2 + bx + c

  • a controla la apertura (arriba o abajo).
  • b afecta la ubicación del vértice.
  • c es la intersección con el eje y.

El vértice

El vértice es el punto más alto o más bajo de la parábola.

Fórmula del vértice:

x = -b 2a

Una vez que tienes la x del vértice, sustituyes en la ecuación para obtener la y.

Intersecciones

  • Intersección con y: ocurre cuando x = 0 → y = c.
  • Intersecciones con x: se encuentran resolviendo la ecuación cuadrática.

Ejemplo

Grafica la función:

y = x2 - 4x + 3

Vértice:

x = -(4) 2(1) = 2

Sustituimos x = 2:

y = 22 - 4(2) + 3 = -1

Vértice: (2, -1)

Intersección con y: (0, 3)

Intersecciones con x: resolver x² - 4x + 3 = 0 → (1, 0) y (3, 0)
