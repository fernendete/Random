2.06 – Solving Quadratic Equations

Una ecuación cuadrática es una ecuación de la forma ax2 + bx + c = 0 . Para resolverla, podemos usar diferentes métodos: factorización, completar el cuadrado y la fórmula cuadrática.

Objetivo: encontrar los valores de x que hacen que la ecuación sea verdadera (las soluciones o raíces).

  • Si la ecuación se puede factorizar fácilmente, usamos factorización.
  • Si no se puede factorizar, podemos usar completar el cuadrado.
  • La fórmula cuadrática funciona siempre que a ≠ 0.

La fórmula cuadrática

La fórmula cuadrática es una herramienta universal para resolver ecuaciones cuadráticas:

x = -b ± b2 - 4ac 2a

El término dentro de la raíz se llama discriminante: D = b2 - 4ac .

  • Si D > 0 → dos soluciones reales distintas.
  • Si D = 0 → una solución real (raíz doble).
  • Si D < 0 → soluciones complejas (no cortan el eje X).

Ejemplo usando la fórmula cuadrática

Resuelve: x2 - 5x + 6 = 0

  1. Identifica a, b, c: a = 1, b = -5, c = 6.
  2. Calcula el discriminante: D = 52 - 4(1)(6) = 25 - 24 = 1
  3. Aplica la fórmula: x = -(-5) ± 1 2(1)
  4. Soluciones: x = 2 y x = 3.
