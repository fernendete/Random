2.05 – Completing the Square

Completing the square es una técnica que convierte una expresión cuadrática en un trinomio cuadrado perfecto. Esto permite resolver ecuaciones, encontrar el vértice y reescribir funciones en forma vértice.

Idea clave: Tomamos el término del medio (b), lo dividimos entre 2 y lo elevamos al cuadrado. Ese número es el “magic number”.

Representación en MathML:

x2 + bx + ( b2 ) 2

  • El coeficiente de x² debe ser 1.
  • El número mágico siempre es (b/2)².
  • El resultado final es un binomio al cuadrado.

Ejemplo paso a paso

Completa el cuadrado para la expresión:

x2 + 6x

  1. Coeficiente de x² = 1 → OK.
  2. b = 6 → b/2 = 3.
  3. (b/2)² = 9.
  4. Agregamos 9 → x² + 6x + 9.
  5. Factorizamos → (x + 3)².

Resultado final:

( x + 3 ) 2

Vertex Form

Completing the square también permite convertir una función cuadrática a forma vértice:

y = a ( x - h ) 2 + k

Donde (h, k) es el vértice.
