1.02 — Functions

Understanding Domain, Range & Function Notation

Next page for content

What is a Function?

A function is a rule that assigns exactly one output to each input. If an input has two different outputs, the relation is not a function.

Example of a valid function:

  • f(3) = 10

Example of NOT a function:

  • f(3) = 10 and 12

Function Notation

The expression f(x) means “the output of the function f when the input is x.”

Example:

f(x)=2x+5

f(3)=2×3+5=11

Domain

The domain is the set of all possible input values (x-values) that the function can accept.

Examples:

  • f(x)=1x → x ≠ 0
  • f(x)=x → x ≥ 0

Range

The range is the set of all possible output values (y-values) the function can produce.

Example:

  • f(x)=x2 → y ≥ 0

Vertical Line Test

A graph represents a function if no vertical line touches the graph more than once.

  • ✔ A straight line → function
  • ✘ A circle → NOT a function
  • ✘ A sideways parabola → NOT a function
