1.04 — Transformations of Functions

Shifts, Reflections, Stretches & Compressions

What Are Transformations?

Transformations change the position, shape, or orientation of a function’s graph.

There are four main types:

  • Vertical Shifts
  • Horizontal Shifts
  • Reflections
  • Stretches & Compressions

These transformations apply to ANY function: linear, quadratic, absolute value, cubic, exponential, etc.

Vertical Shifts

Vertical shifts move the graph up or down.

General form:

f(x)+k

  • k > 0 → moves UP
  • k < 0 → moves DOWN

Example:

g(x)=x2+3

This moves the parabola up 3 units.

Horizontal Shifts

Horizontal shifts move the graph left or right.

General form:

f(x-h)

  • h > 0 → moves RIGHT
  • h < 0 → moves LEFT

Example:

g(x)=(x-4)2

This moves the parabola right 4 units.

Reflections

Reflections flip the graph across an axis.

Reflection across the x-axis

-f(x)

Flips the graph upside down.

Reflection across the y-axis

f(-x)

Flips the graph left-right.

Stretches & Compressions

These transformations change the shape of the graph.

Vertical Stretch

af(x)

If a > 1, the graph becomes taller.

Vertical Compression

If 0 < a < 1, the graph becomes flatter.

Horizontal Stretch/Compression

f(bx)

  • b > 1 → horizontal compression
  • 0 < b < 1 → horizontal stretch
