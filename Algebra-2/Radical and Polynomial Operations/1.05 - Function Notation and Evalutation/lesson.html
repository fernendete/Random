1.05 — Function Notation & Evaluation

Understanding f(x) and how to evaluate functions

What Is Function Notation?

Function notation replaces y with f(x). It tells you the output of a function when the input is x.

Example:

f(x)=2x+3

Evaluating Functions

To evaluate a function, substitute the input value into x.

Example:

f(x)=3x-2

Evaluate f(4):

f(4)=3×4-2=10

Functions in Tables

Tables show input-output pairs that follow a rule.

xf(x)
03
15
27

This matches f(x) = 2x + 3.

Domain & Range

The domain is the allowed x-values. The range is the possible outputs.

Example:

g(x)=x

  • Domain: x ≥ 0
  • Range: g(x) ≥ 0

Functions in Real Life

Functions can model real situations.

If f(x) = 50x represents earning $50 per hour:

  • f(1) = 50 → $50 earned
  • f(3) = 150 → $150 earned
