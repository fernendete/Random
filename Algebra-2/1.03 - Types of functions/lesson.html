1.03 — Types of Functions

Linear, Quadratic, Absolute Value & More

What Are Function Types?

Functions come in many shapes and behaviors. Each type has its own graph, equation form, and characteristics.

In this lesson, we will look at the most common types:

  • Linear Functions
  • Quadratic Functions
  • Absolute Value Functions
  • Exponential Functions
  • Cubic Functions

Linear Functions

A linear function forms a straight line. Its equation is:

f(x)=mx+b

Characteristics:

  • Constant rate of change
  • Slope (m) tells how steep the line is
  • y-intercept (b) tells where the line crosses the y-axis

Quadratic Functions

A quadratic function forms a parabola. Its equation is:

f(x)=x2+bx+c

Characteristics:

  • U-shaped graph (opens up or down)
  • Has a vertex (minimum or maximum)
  • Rate of change is NOT constant

Absolute Value Functions

An absolute value function forms a V-shaped graph. Its equation is:

f(x)=|x|

Characteristics:

  • Sharp corner at the vertex
  • Symmetric
  • Piecewise behavior

Exponential Functions

An exponential function grows or decays rapidly. Its equation is:

f(x)=abx

Characteristics:

  • Growth if b > 1
  • Decay if 0 < b < 1
  • Never touches the x-axis

Cubic Functions

A cubic function has an S-shaped curve. Its equation is:

f(x)=x3+bx+c

Characteristics:

  • Can increase, decrease, then increase again
  • Has inflection point
  • Not symmetric
