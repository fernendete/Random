Understanding (f ∘ g)(x) and How Functions Combine

What is a Composition of Functions?

A composition of functions is when you plug one function inside another function.

It looks like this:

(f ∘ g)(x) = f(g(x))

This means: first evaluate g(x), then take that result and plug it into f(x).

Example

f(x) = 2x + 1
g(x) = x - 3

Find (f ∘ g)(x):

Step 1: g(x) = x - 3
Step 2: f(g(x)) = f(x - 3)
Step 3: f(x - 3) = 2(x - 3) + 1 = 2x - 6 + 1 = 2x - 5

So the composition is: 

(f ∘ g)(x) = 2x - 5

Evaluating Compositions

To evaluate a composition at a number, follow the same steps:

Example

f(x) = x²
g(x) = 4x

Find (f ∘ g)(2):

Step 1: g(2) = 4(2) = 8
Step 2: f(8) = 8² = 64

So (f ∘ g)(2) = 64

Order Matters

Compositions are NOT reversible. (f ∘ g)(x) is usually NOT the same as (g ∘ f)(x).

Example

f(x) = x + 1
g(x) = 3x

(f ∘ g)(x) = f(g(x)) = f(3x) = 3x + 1

(g ∘ f)(x) = g(f(x)) = g(x + 1) = 3(x + 1) = 3x + 3

They are different!

Decomposing Functions

Sometimes you are given a complicated function and asked to break it into two simpler functions f(x) and g(x).

Example

Given: h(x) = (3x + 1)²

One possible decomposition:
g(x) = 3x + 1
f(x) = x²

Then: (f ∘ g)(x) = f(g(x)) = (3x + 1)²

There are many valid decompositions — you just need two functions that combine to make the original.
