1.01 — Rational Exponents

How can an expression written in either radical form or rational exponent form be rewritten to fit the other form?

Understanding Rational Exponents

A rational exponent is simply an exponent that is written as a fraction. It provides a clean, algebraic way to represent root calculations (like square roots or cube roots) using standard exponent notation.

The Golden Key Rule: The denominator of the fractional exponent represents the root index, while the numerator represents the power.

Core Definition in MathML:

x m n = x m n = ( x n ) m

Where:

  • x is the base.
  • m is the power (numerator).
  • n is the index of the root (denominator).

Converting Radical to Exponent Form

To rewrite a radical expression as an exponent expression, find the base, place the power inside as the numerator, and place the index outside as the denominator.

Example 1: Basic Root Conversion

y 5 3 = y 5 3

The index is 3 (denominator) and the power is 5 (numerator).

Example 2: Square Root with Hidden Power

w = w 1 2

Recall that a standard square root has a hidden index of 2 and a hidden power of 1.

Converting Exponent to Radical Form

To simplify and evaluate expressions with rational exponents, converting them into radical form makes it easier to work out the values mentally.

Example 1: Numerical Evaluation

8 2 3 = ( 8 3 ) 2 = 2 2 = 4

• Step 1: Take the cube root (index 3) of 8, which equals 2.

• Step 2: Square the result (power 2), which gives you 4.

Example 2: Negative Base Rules

( - 27 ) 1 3 = - 27 3 = - 3

Since the index is odd (3), we can take the root of a negative base in real numbers.
