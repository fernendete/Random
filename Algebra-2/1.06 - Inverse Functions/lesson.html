1.06 — Inverse Functions

Undoing a function and reversing inputs & outputs

What Is an Inverse Function?

An inverse function reverses the original function.

If a function takes x → y, the inverse takes y → x.

Notation:

f-1(x)

How to Find an Inverse

To find an inverse algebraically:

  1. Replace f(x) with y
  2. Switch x and y
  3. Solve for y
  4. Rewrite y as f⁻¹(x)

Example:

f(x)=2x+3

Step 1: y = 2x + 3

Step 2: Switch → x = 2y + 3

Step 3: Solve → y = (x - 3)/2

So:

f-1(x)= x-32

Graphing Inverse Functions

The graph of an inverse is a reflection across the line y = x.

If a point (a, b) is on f(x), then (b, a) is on f⁻¹(x).

When Does an Inverse Exist?

A function must be one-to-one to have an inverse.

Use the Horizontal Line Test:

  • If any horizontal line touches the graph more than once → NO inverse.
  • If every horizontal line touches once → inverse exists.
