What is a Piecewise Function?

A piecewise function is a function that is defined by different formulas depending on the value of x.

Example:

f(x) = { x+2 if x0 3 if x=0 x2 if x>0

This means the function behaves differently depending on the region of x.

Evaluating Piecewise Functions

To evaluate a piecewise function, you must:

  • Check which condition x satisfies
  • Use the formula for that region

Example

g(x) = { 2x if x1 x+4 if x>1

Find g(1):

x=1→ use 2x

g(1) = 2×1 =2

Graphing Piecewise Functions

When graphing a piecewise function:

  • Graph each piece separately
  • Use open or closed circles depending on the condition
  • Make sure the graph switches formulas at the correct x-value

Example

h(x) = { 1 if x0 x if x≥0

At x = 0, the second piece applies, so the point (0, 0) is a closed circle.
