What is a Piecewise Function?

A piecewise function is a function that uses different formulas depending on the value of x.

Example (written without MathML tables):

    f(x) = x + 2    if x < 0
    f(x) = 3        if x = 0
    f(x) = x²       if x > 0

This means the function behaves differently depending on the region of x.

Evaluating Piecewise Functions

To evaluate a piecewise function:

  • Check which condition x satisfies
  • Use the formula for that region

Example

    g(x) = 2x       if x ≤ 1
    g(x) = x + 4    if x > 1

Find g(1):

    Since 1 ≤ 1, use 2x:
    g(1) = 2(1) = 2

Graphing Piecewise Functions

When graphing a piecewise function:

  • Graph each piece separately
  • Use open circles for < or >
  • Use closed circles for ≤ or ≥
  • Switch formulas at the correct x-value

Example

    h(x) = 1     if x < 0
    h(x) = x     if x ≥ 0

At x = 0, the second piece applies → closed circle at (0, 0).
