What is a Piecewise Function?

A piecewise function is a function defined by different formulas depending on the value of x.

Example:

f(x)= { x+2 if x0 3 if x=0 x2 if x>0

Evaluating Piecewise Functions

To evaluate a piecewise function:

  • Check which condition x satisfies
  • Use the formula for that region

Example

g(x)= { 2x if x1 x+4 if x>1

Find g(1):

g(1)=2×1=2

Graphing Piecewise Functions

When graphing:

  • Graph each piece separately
  • Use open or closed circles depending on the condition
  • Switch formulas at the correct x-value

Example

h(x)= { 1 if x0 x if x≥0

At x = 0, the second piece applies → closed circle.
