What is a Linear Function?

A linear function is any function whose graph is a straight line. It has the form: 

f(x) = mx + b

Where:

  • m = slope
  • b = y-intercept

Example

f(x) = 3x - 2
Slope: 3
Y-intercept: -2

Understanding Slope

The slope tells you how steep the line is. It is the rate of change: 

slope = rise / run

Example

Slope = 2
Means: for every 1 unit right, the line goes up 2 units.

Positive slope → line goes up Negative slope → line goes down Zero slope → horizontal line Undefined slope → vertical line

Graphing Using Slope and Intercept

To graph a line using slope-intercept form:

  1. Plot the y-intercept (b)
  2. Use the slope (m) to find another point
  3. Draw the line through the points

Example

f(x) = -2x + 4

Step 1: y-intercept = 4 → plot (0, 4)
Step 2: slope = -2 → go down 2, right 1
Step 3: connect the points

Graphing Using a Table

Another way to graph a linear function is by making a table of values.

Example

f(x) = x + 1

Choose x-values: -1, 0, 1, 2

x   | f(x)
--------------
-1  | 0
0   | 1
1   | 2
2   | 3

Plot the points and connect them.
